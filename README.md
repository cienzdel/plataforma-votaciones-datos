# Archivo público de votaciones · Public voting archive

**ES** · Aquí publica la plataforma [plataforma-votaciones](https://github.com/snatip/plataforma-votaciones), y solo ella, los documentos de cada votación: avisos de apertura, tablones, tablas de candidaturas, listas nominales, sorteos, asentimientos y la cadena de hashes (`chain.json`). Lo sirve GitHub Pages para que cualquiera pueda comprobar los resultados con la [herramienta de verificación](https://github.com/snatip/plataforma-votaciones/tree/main/tools/verify), aunque la plataforma esté apagada. El formato está en [`spec/formats.md`](https://github.com/snatip/plataforma-votaciones/blob/main/spec/formats.md).

**EN** · The [voting platform](https://github.com/snatip/plataforma-votaciones), and only the platform, publishes here the documents of every voting: opening notices, boards, candidates tables, roll-call lists, draws, assents and the hash chain (`chain.json`). GitHub Pages serves them so that anyone can check the results with the [verification tool](https://github.com/snatip/plataforma-votaciones/tree/main/tools/verify), even while the platform is off.

No se edita a mano · Do not edit by hand.
